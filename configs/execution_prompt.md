## 4. 固定的一维与二维方程

记 `div_axis(a grad U) = (1/r)∂r(r*a*∂r U) + ∂z(a*∂z U)`；一维省略轴向项。

固定尺寸（第一问及第二、三问）：
```
rho(C)*cp(C)*∂t T = div_axis(k(C)*grad T)
∂t C = div_axis(D(T,C)*grad C)
```

注意：
- 系数必须在通量散度中，不得把 `div(D grad C)` 改成 `D Laplacian(C)`。
- 热通量散度先计算，再除以本地 rho*cp，不改成 `div((k/rho/cp) grad T)`。
- 不将左侧改成 `∂t(rho*cp*T)`，不随意添入 cp'(C)*C_t 项。
- 当前 C 方程是题面量构成的有效含水率扩散模型，数值水分通量不得直接标成 kg/s 的绝对质量流率。

一维范围：`0 <= r <= R0`。

二维范围：`0 <= r <= R0, 0 <= z <= L/2`；z=0 是中截面，z=L/2=0.125 m 才是暴露端面。

边界（n 为向外法向）：
```
r=0：∂r T=0，∂r C=0
二维 z=0：∂z T=0，∂z C=0
侧面和暴露端面：
-k*∂n T = h*(Ts-Tenv)
-D*∂n C = hm*(Cs-Henv)
```

不得把有限交换边界改成 `Ts=Tenv` 或 `Cs=Henv`。
所有案例从原始 T0、C0 启动，不为匹配初始表面通量而预先改低表面含水率。

### 第四问的随体坐标

令 `xi=r/R(t)`，材料点的 xi 和 z 不变。采用：
```
rho4*cp4*∂t T =
    1/(R²*xi) * ∂xi(xi*k4*∂xi T) + ∂z(k4*∂z T)

∂t C =
    1/(R²*xi) * ∂xi(xi*D4*∂xi C) + ∂z(D4*∂z C)
```
一维省略 z 项。轴向长度固定，因此 z 项不乘径向缩放系数。

侧面 xi=1：
```
-(k4/R)*∂xi T = h*(Ts-Tenv)
-(D4/R)*∂xi C = hm*(Cs-Henv)
```
端面仍用真实 z 导数的原边界。

不得在这个最终随体方程中再次加收缩平流项，不添加“体积压缩导致 C 增浓”的项。C 是质量比，不是体积浓度。用实际几何有限体积实现等价方程时，要保留 `V*dC/dt`，不得擅自换成 `d(V*C)/dt`。所有面积、体积、距离在同一 RK4 子阶段使用同一 R(t)。

## 6. 数值实现与验证：先跑通，不无限加密

### 6.1 空间离散

优先单元中心有限体积。初始生产候选：
```
1D：Nr=40
2D：Nr=40、Nz=125（Nz 对应半长 0.125 m）
```
格数是数值配置，不是题面条件，也不预先宣称已足够。

圆柱控制体含正确几何权重：
- 一维单位轴长体积：pi*(r_outer²-r_inner²)。
- 二维体积：pi*(r_outer²-r_inner²)*dz。
- 径向面面积：2*pi*r_face*dz；轴向面为圆环面积。
- 轴线零面积面自然零通量，不直接在 r=0 除以零。
- 相邻公共面只计算一次等量反号通量。变系数面值采用一致的串联阻力/调和处理，并做空间收敛检查。

边界保留半单元与外界交换两段阻力。例如：
```
qT_out=(TP-Tenv)/(delta/kP+1/h)
Ts=Tenv+qT_out/h
qC_out=(CP-Henv)/(delta/DP+1/hm)
Cs=Henv+qC_out/hm
```
这是离散近似，不是假定边界 D 恒定。强变系数情况下检查重构与网格加密；不得用最后一个单元平均值冒充真实表面值。

中心、对称面、端面与角点应使用与所存变量一致的重构。若变量为均匀径向环形单元平均值，可用 `(5*U0-U1)/4` 作轴心二次重构；半长轴向平均值可用 `(7*U0-U1)/6` 作中截面对称重构。若改成点值或非均匀网格，要重新推导，不能混用这些公式。角点不能重复算同一表面通量。

### 6.2 RK4 与稳定性

实现明确的四阶段 RK4。每个阶段同步更新 T、C、物性、环境和几何。不能先整步更新温度，再以旧温度整步更新水分；也不能使用 RK45 后仍称经典 RK4。

```

sC = sum(face_moisture_conductances)/V
dt_bound = safety * 2.7852935634/(2*max(sT,sC))
```

## 7. 一维—二维逐点比较

按同一物理时间、同一 r 取值：
```
deltaT(r,z,t)=T_2d(r,z,t)-T_1d(r,t)
deltaC(r,z,t)=C_2d(r,z,t)-C_1d(r,t)
```
一维沿 z 复制只用于建立参考场；二维必须真实求解。

第四问使用实际 `r=xi*R(t)` 比较，不把不同网格的相同索引当成同一位置。需要插值时保存方法和采样分辨率。

比较包括全域、中截面、端面和沿 z 的分布，不只比较中心或结束时长：
- 各时刻最大绝对温差、最大绝对含水率差；
- 最大误差出现的 r、z、t；
- 按柱坐标体积权重计算的 RMSE；
- 中截面/端面及中段/端部的分区结果，分区由明确坐标定义；
- 两种维数各自烘干时间及相对差（以一维时长为分母）；任一未达标则相对差为空，不填 0。

暂定端面影响比较标准：
```
max |deltaT| <= 0.2 ℃
max |deltaC| <= 0.003 kg/kg
relative drying-time difference <= 1%（q23/q4）
```
第一问没有烘干时间条件。只有实际评估范围内的各项都通过才标为通过；时间/空间采样不足或数值误差未充分验证时，标为“暂定/未验证”，不要给确定的全域结论。

建议比较采样：第一问与 q23 前 3 h 每 1 s，后续与 q4 每 60 s，另含指定关键时刻及终点；保留更密采样能力。最大误差明确指这些实际评估时刻，不冒充连续时间严格上界。

差值只输出数值表、二维曲线和少量二维热图；不生成差值 GIF、差值三维图。
偏差超标仍保留一维输出来源，不改题目参数、不删端部数据、不改变阈值以迎合结论。

资源策略：
- 目标为 16GB 内存 Windows 游戏本，默认 CPU。
- RK4 长循环、物性和通量计算尽量 Numba 编译，禁止每个时间步在 Python 中逐单元循环；避免每步反复分配大数组。
- Numba 快速数学默认关闭，先保证数值一致。首编译耗时单独记录。
- 先短段实测本机吞吐、峰值内存，估计各长案例成本；不要复用聊天中的异机估计当实测。
- 一次一个重型二维任务；不要启动多个细网格长任务抢内存。
- 目标主计算/后处理各自不超过约 4GB 内存，预算不足时分块或磁盘映射。
- 不将 72 h 内每秒的完整二维场全放 RAM；一维输出、二维比较所需场、动画帧分开管理。
- 原始全精度缓存用数组格式，按时间分块；不要用 JSON 存放大矩阵。
- 每个案例保存可续算检查点，含配置/输入哈希和状态；不匹配的缓存拒绝复用。
- 进度显示真实模拟时刻、已算比例、实际耗时与剩余估计。不能进度条长期假装 99%，也不每步刷屏。
- 初版不做所有网格、步长的笛卡尔积扫描，不默认进行高成本附加物理实验。
- 不设置未经用户授权的关机任务，不改系统全局设置。

```

```
允许合理调整命令命名，但 README 必须给出可直接运行的真实命令。支持断点续算与仅后处理，不只提供不可调用的库函数。

## 12. 实际执行次序与本轮交付

按以下顺序实施并运行，不先写报告：

1. 数据、模板核对，构建参数模块、输入函数和最小测试。
2. 跑通 q1 一维，检查轴线、表面、单位和导出。
3. 实际计算 q23、q4 一维，先得到四问候选结果及事件/未达标状态。
4. 完成一维真实缩步及必要空间核验，修复程序错误，不改物理假设；导出来源一致的结果。
5. 运行三类二维核验，完成同位置比较；再做有针对性的数值复核，记录覆盖范围。
6. 导出唯一的四份官方一维 Excel、各问曲线/比较/最大误差截面 PNG、两张三维静态图、两个三维 GIF，以及 q3/q4 过轴和圆形径向截面综合 GIF；输出布局以 README 为准。
7. 回读输出并检查状态、来源、终点、空白语义；将数值失败、端面偏差、展示失败分别汇总。

本轮交付是：可运行源代码、四问实际计算结果或明确未达标/未通过状态、输入配置与假设记录、测试和数值复算的机器可读数据、所要求的图和 GIF、可定位错误日志。不要生成技术报告、论文、论文提纲或“结果还没算但文章已写好”的文档。

最终只用简短文字说明：
- 实际执行过的命令、测试和案例；
- 一维第三、四问的烘干时间，或“72 h 内未烘干”；
- 二维比较是否通过、数值验证哪些通过/失败/未完成；
- 结果、图像和日志路径；
- 实测运行时间与内存、仍存在的具体问题。

没有真实运行不得声称已得到结果；只有运行成功且数值核验通过的配置才能标为成功完成。执行中保留已完成工作的有效产物，不因一个可分离任务失败而整批重算。
