# 完整功能 GUI 版

双击本目录“药材烘干模型_GUI.exe”，或安装本目录 requirements 后运行同名 .py。
本版依赖、源码、work/results/logs 均独立，不读取终端版，也不向其他发布目录写入数据。
无需预先保留结果或缓存；首次运行自动创建目录。

- A · 四表正式数据：问题1、问题2/3共享轨迹、问题4，分别缓存。
- B · 创新实验数据：逐个二维基础场、热效应、环境尾窗和几何实验。
- C · 绘图：30 张图/动画逐项选择，只读取已有数据，不调用求解器。
- D · 验证（耗时最长，建议不做）：逐项验证，保留热效应严格验证18项、水质量守恒12项。

“刷新缓存”核对本目录已注册数据的科学身份、文件存在性与 SHA256。
例如问题1、问题2/3已有缓存而问题4未完成，C/D 中仅依赖前两项的数据任务可选，问题4相关项禁用。
二维图还需要对应二维基础数据；二维验收汇总还需要对应的验证证据。
缺项直接显示在每行右侧，悬停可查看原因。文件丢失或失效后取消对应选择。
扫描在后台进行，不启动计算；扫描失败时 C/D 保持禁用，可重新刷新。

每个模式、子组均支持全选/全不选；“全选”只选择当前可用项，跳过禁用项。
“仅四表”选择 A；“论文数据（A+B）”准备基础数据，不附带绘图或验证。
选择 A/B 不会提前解锁缺数据的 C/D。先生成所需数据，刷新后再选 C/D。
D 默认折叠，开始前只确认一次；强制重算数据和验证分别控制。

开始、立即停止和进度始终可见，不随长列表滚走。
总进度在一轮内保持单调；剩余时间不确定时暂保持并提示校准，不显示循环条。
阶段与各模式完成项数单独显示；只有所选任务全部成功才显示100%。
立即停止结束本窗口启动的计算进程树；关闭窗口时一并停止。
下一轮只复用核验有效的缓存，未完成输出不能冒充完成。

系统保留内存为总内存的12%，最低384 MiB、最高2048 MiB，没有固定2 GiB启动门槛。
低内存降低并发；单任务放不下时报告 MEMORY_REQUIREMENT_UNSATISFIED 及预计需求、available、reserve。
复用常驻计算进程时只计算新增内存需求，不降低网格、步长或精度。

数值核心、正式 Excel 格式和收敛阈值不变。D 未运行不声称验证 PASS；旧 fixed-grid 仅为历史诊断。
本轮只进行少量界面/状态检查，不执行 PDE 复算、全量绘图或完整数值验证。
