# 补充热模型的闭合与量纲

正式 M00 不变。M10 仅边界潜热，M01 仅水分显式携热，M11 两项均计。

C 的单位为 kg 水/kg 干料；jC = −D∇C 的单位为 m/s。
初态干料体积密度 b0 = ρ(C0)/(1+C0)，干料质量 Md = b0 πR0²L。
固定长度和均匀径向变形给出 b(t)=Md/V(t)=b0(R0/R(t))²，Jw=b jC，单位 kg/(m² s)。
b 在空间上均匀，不能以局部经验 ρ(C)/(1+C) 替代。经验热容 K=ρ(C)cp(C) 独立保留。

采用题给有效温度方程的补充闭合：

    K DT/Dt = div(k grad T) − χM Jw·grad hl(T)

坐标已经随材料变形，不再加入材料运动的第二个对流项。
从 div(hl Jw)=Jw·grad hl+hl div Jw 可见，直接采用 −div(hl Jw) 会额外增加 −hl div Jw。
本工程采用相邻单元共享的带符号水通量，单元显式源为
−Σf Af Jw,out (hl,upwind−hl,i)/Vi。焓差不受任意焓零点影响，均温时严格为零。
边界流出用单元焓，流入用真实边界温度的液态焓。它是有效温度闭合，不声称完整混合物总能量守恒。

外边界在每个 RK 子步联立水分 Robin、当前内侧物性和边界温度：

    jC = conductance(Di, dr, hm)(Ci−H∞)
    Cs = H∞ + jC/hm
    h(T∞−Ts) = ki(Ts−Ti)/dr + χL Lv(Ts) b jC

Di、ki 与原离散一致，采用该子步内侧单元 T、C；Lv 采用同一子步求出的 Ts。
热边界 Newton 迭代使用分段线性水表的导数，收敛后复核通量残差；不冻结上一子步边界值。
负 j 表示凝结，潜热项保留符号；不截零。潜热只在外边界，不另加体积 −dC/dt 潜热。

hl 与 Lv 来自 IAPWS-IF97 饱和液态/饱和蒸汽，库的 kJ/kg 明确乘 1000 转为 J/kg。
dhl/dT 是沿饱和路径的导数，不能冒称定压 cp。
当前实现温区为 273.16–373.15 K，禁止跨入冰区或表外外推。
冷却到 28 °C 以下允许；越过物性有效域立即留下诊断，不裁剪温度。

RK4 复用正式内核原函数体，只注入补充通量算子。
稳定限制包括原扩散行和、携热上风通量行和以及边界热通量对温度/含水率的耦合估计。
耦合范数使用 50 K 与 2.55 kg/kg 的固定尺度；其保守估计仍需各模型实际半步重放验证。
换网格仍用原精确环形体积重叠投影，并记录 ΣVC、ΣVK(T−273.15 K) 的变化；后者仅为指定参考温度下的有效储热指标。
每个热模式单独定位事件、进行全阶段空间参考和实际步长二分重放，不借用 M00 的 PASS。
